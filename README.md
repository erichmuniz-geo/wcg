# Ande Corajosamente — GitHub Pages

Pacote otimizado para publicação direta no GitHub Pages.

## Publicação
1. Envie **todo o conteúdo desta pasta** para a raiz do repositório.
2. Confirme que `index.html` aparece na primeira tela do repositório.
3. Em **Settings → Pages**, selecione `Deploy from a branch`, branch `main`, pasta `/(root)`.
4. Aguarde a conclusão da ação `pages build and deployment`.

Não altere o nome da pasta `imagens`.
